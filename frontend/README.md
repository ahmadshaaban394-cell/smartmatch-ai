# SmartMatch AI Frontend

React frontend for the SmartMatch AI freelance matching platform.

## Main Features

- Client and freelancer authentication
- Role-based dashboards
- Freelancer profile management
- Job posting and application management
- Ranked job and freelancer recommendations
- PDF upload and AI-service integration

## Run Locally

```bash
npm install
npm start
```

The frontend normally opens at:

```text
http://localhost:3000
```

The Node.js backend should run on port `8000`, and the FastAPI AI service should run on port `9000`.
